# scratchpad

## Build

Windows 10/11 with the Rust toolchain (MSVC) and the Windows SDK installed.

```powershell
cargo run -p scratchpad              # debug build, logs to the console
cargo build --release -p scratchpad  # target/release/scratchpad.exe; slow: fat LTO over GPUI
cargo test --workspace
```

Set `SCRATCHPAD_NOTES_DIR` to point the app at another notes folder, e.g. to try it on a
scratch folder.

## Install

The installer is a per-user MSI: it needs no administrator rights, installs to
`%LOCALAPPDATA%\Programs\Scratchpad`, adds a Start Menu shortcut and an uninstall entry, and a
newer MSI upgrades an existing install in place. Uninstalling leaves your notes and settings alone.

To build it (needs the .NET SDK; WiX is restored as a repo-local tool, nothing is installed
system-wide):

```powershell
powershell -File packaging/build-installer.ps1   # -> target/installer/Scratchpad-<version>-x64.msi
```

The app icon is generated by `assets/icons/generate-icon.ps1`.
